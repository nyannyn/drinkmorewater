隱私權政策

適用於「喝水提醒」桌面版與 iOS 版 · 最後更新 2026-09-11

我們收集什麼

不收集。所有飲水紀錄與設定（每日飲水量、目標、提醒間隔、語言、主題等）僅儲存在你的裝置上。本程式不含任何追蹤、分析、廣告或遙測，也不會把資料傳給開發者或任何第三方。

網路連線

預設不進行任何網路連線。唯一的例外是你主動啟用「跨裝置同步」並填入自己架設的伺服器網址：此時 App 只會把你的每日飲水貢獻與設定送到你指定的那台伺服器，以裝置配對碼識別，不需要帳號、email 或密碼。伺服器由你自行管理，開發者無法存取其中的資料。

通知

iOS 版會請求通知權限，用於在本機排程「該喝水了」的提醒。通知完全由裝置作業系統在本機觸發，不經過任何推播伺服器。

資料刪除

解除安裝 App 即刪除裝置上的所有資料。若曾啟用跨裝置同步，伺服器端資料由你自己的伺服器保管，可自行刪除。

兒童

本程式不收集任何個人資料，因此亦不會收集兒童的個人資料。

原始碼與聯絡

原始碼完全公開：github.com/nyannyn/drinkmorewater。任何問題請至 GitHub Issues 提出。

Privacy Policy

Applies to Drink Water Reminder for desktop and iOS · Last updated 2026-09-11

What we collect

Nothing. All hydration records and settings (daily intake, goal, reminder interval, language, theme, etc.) are stored only on your device. The app contains no tracking, analytics, advertising, or telemetry, and never sends data to the developer or any third party.

Network access

No network requests are made by default. The only exception is when you explicitly enable Cross-device Sync and enter the address of a server you host yourself. The app then sends only your daily intake contributions and settings to that server, identified by a device pairing code — no account, email, or password. The server is under your control; the developer cannot access its data.

Notifications

The iOS app asks for notification permission to schedule local "time to drink" reminders. Notifications are triggered on-device by the operating system and never pass through a push server.

Data deletion

Uninstalling the app deletes all data on the device. If you used Cross-device Sync, server-side data lives on your own server and can be deleted there.

Children

The app collects no personal data from anyone, including children.

Source code & contact

The source code is fully open: github.com/nyannyn/drinkmorewater. Questions go to GitHub Issues.
