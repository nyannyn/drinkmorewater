# 📱 iOS 實機 / 模擬器 測試清單

> 容器是 Linux，無法跑 Xcode / 模擬器，本檔列出**必須上機才能驗證**的項目。
> 建議用設定頁的「🔔 傳送測試通知」按鈕逐項勾選。

## 0. 前置

```bash
cd mobile
npm install
# macOS + Xcode：
npx expo run:ios
# 或免 Mac，雲端 dev build（需 Expo 帳號）：
npx eas build --platform ios --profile development
```

- [ ] App 能啟動，首次出現系統通知授權窗，按「允許」
- [ ] 拒絕授權 → 重開後 console 有 `permDenied` 警示（到「設定 → 喝水提醒 → 通知」可手動開）

---

## 1. 通知送達

- [ ] 設定頁按「傳送測試通知」→ 約 3 秒後收到通知
- [ ] App 在**前景**時也跳橫幅（foreground handler 生效）
- [ ] App 切**背景 / 鎖屏**時收得到通知
- [ ] 音效開關開啟時有「叮」聲；關閉時靜音
- [ ] 等一個提醒間隔（可暫時設 15 分）確認**排程通知**自動送達，非只有測試鈕

---

## 2. 4 語通知外觀

切換設定頁語言後各按一次測試通知，確認標題 / 內文正確且不截斷：

| 語言 | 標題 | 內文 | 勾選 |
|---|---|---|---|
| 繁中 | 💧 該喝水了！ | 你已經很久沒喝水了，記得補充水分哦！ | [ ] |
| 簡中 | 💧 该喝水了！ | 你已经很久没喝水了，记得补充水分哦！ | [ ] |
| 英 | 💧 Time to drink! | You haven't had water in a while — stay hydrated! | [ ] |
| 日 | 💧 水を飲む時間です！ | しばらく水を飲んでいません。水分補給を忘れずに！ | [ ] |

- [ ] 切語言後 App 內文字（首頁 / 設定 / 週圖星期）即時跟著變

---

## 3. 「我喝了」動作鈕

- [ ] 下拉 / 長按通知可見動作鈕，文字隨語言本地化：
  - 繁中「我喝了 💧」/ 簡中「我喝了 💧」/ 英「I drank 💧」/ 日「飲んだ 💧」
- [ ] 點動作鈕**不開 App** 即記錄一次（今日杯數 +1、水量 +drinkMl）
- [ ] 點動作鈕後會重排下一輪提醒
- [ ] 點通知本體（非動作鈕）→ 開 App 並停在首頁

---

## 4. 排程行為（背景補排）

- [ ] 設定頁「已排定 N 則提醒」數字合理（活躍時段 × 間隔，≤ 60）
- [ ] 活躍時段外不應收到提醒（可把活躍時段設成目前時間之外驗證）
- [ ] App 進前景會重排（跨日後今日數據歸零、上一日進週統計）
- [ ] 改間隔 / 活躍時段 / 啟用開關後，排程數字即時更新
